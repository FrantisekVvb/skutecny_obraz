# skutecny_obraz

Jednoduchá interaktivní simulace optické lavice v čistém HTML/Canvas.

## Spuštění

- **Nejjednodušší**: otevři `index.html` v prohlížeči.
- **Doporučené (lokální server)**:
  - `npm run dev`
  - pak otevři `http://localhost:5173`

## Publikování na GitHub Pages

Repozitář je připravený na automatické nasazení přes GitHub Actions.

- V GitHubu v repozitáři otevři `Settings` → `Pages`
- V části **Build and deployment** vyber:
  - **Source**: `GitHub Actions`
- Po pushi do větve `main` se stránka nasadí a GitHub ti ukáže výslednou adresu.

## Ovládání

- Táhni **plamínek** (vlevo) a **stínítko** (svislá černá čára) po optické ose.
- Přepínej typ čočky: **Spojka / Rozptylka**.
